# Unit Converter

A simple **unit-conversion tool** written in Python — converts between common units
(length, weight, temperature, etc.) from the command line. A clean beginner project
showing functions, user input, and basic arithmetic conversion logic.

## Features
- Convert between common units
- Menu-driven command-line interface
- Clear, reusable conversion functions

## Run it
```bash
git clone https://github.com/furqunali/Unit-convertor.py.git
cd Unit-convertor.py
python Unit-convertor.py
```

## Concepts demonstrated
Functions · user input · conditional logic · arithmetic conversions
